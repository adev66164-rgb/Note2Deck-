# Note2Deck AI

An AI-powered web app built with HTML, Tailwind CSS, and Gemini API that instantly converts textbook notes into interactive 3D flashcards and a self-test practice quiz.

## Features
- **AI Flashcards:** Automatically generates 3D flip-cards from messy notes or textbook text.
- **Practice Quiz:** Creates a 5-question multiple-choice test with instant answer verification.
- **Demo Mode:** Includes pre-loaded sample notes so users can test it instantly without an API key.

## Built With
- HTML5
- Tailwind CSS
- JavaScript
- Google Gemini API
